// Guía de instalación

De cero a jugando en tres pasos.

No hace falta instalar Minecraft, Fabric ni los mods por separado. El launcher se encarga de todo eso apenas iniciás sesión.

1

Descargá el instalador

Bajá el archivo Enena-Launcher-Setup.exe desde la sección de descargas de arriba. Es el único archivo que necesitás.

⚠️ Windows va a mostrar un aviso de "Editor desconocido" la primera vez — es normal, el launcher todavía no tiene firma digital. Hacé click en "Más información" → "Ejecutar de todas formas".
2

Instalá y abrí el launcher

Corré el instalador, elegí dónde instalarlo, y abrí Enena Launcher. Vas a ver la pantalla de inicio de sesión.

Elegí Premium si tenés una cuenta de Minecraft comprada (te va a abrir una ventana oficial de Microsoft), o Offline si querés entrar solo con un nombre de usuario.

3

Apretá Jugar

El launcher va a verificar que tengas Java 21+, descargar el modpack la primera vez, e iniciar Minecraft automáticamente. La primera vez tarda más — las siguientes veces es casi instantáneo.

Podés seguir todo el proceso en tiempo real desde la pestaña Consola del launcher.

// Soporte

Preguntas frecuentes

Lo que más nos preguntan en Discord, respondido acá para no hacerte esperar.

El launcher dice que necesito Java 21+ pero ya lo tengo instalado
Puede que tengas otra versión de Java más vieja instalada antes en el PATH de Windows. Andá a Ajustes dentro del launcher y seleccioná manualmente el archivo java.exe (no javaw.exe) de tu instalación de Java 21, normalmente en C:\Program Files\Eclipse Adoptium\jdk-21...\bin\.
La descarga del modpack se traba o se corta
El launcher reintenta la descarga automáticamente y retoma desde donde se cortó, así que no hace falta que hagas nada — solo esperá. Si tu antivirus está escaneando cada archivo mientras se instala, puede ir más lento; agregar la carpeta del juego a las exclusiones de Windows Defender ayuda bastante.
Minecraft no abre después de que termina de cargar
Revisá la pestaña Consola del launcher — ahí vas a ver el error exacto (memoria insuficiente, versión de Java incorrecta, etc). Si no te queda claro, pasanos una captura de esa pantalla en el Discord de soporte.
¿Cómo cambio mi skin?
Desde la pestaña Skin del launcher, con una cuenta Premium iniciada. Elegí una imagen PNG y subila directo — se actualiza en los servidores oficiales de Mojang.
¿El launcher se actualiza solo?
Sí. Cada vez que abrís el launcher, revisa si hay una versión nueva y la instala sola en segundo plano. No necesitás volver a descargar nada manualmente.
